# Astryx releases

Release files for the Astryx launcher.

- Minecraft **1.8.9**, Forge **11.15.1.2318**.
- `manifest.json` lists the current release, pinned JAR URL and SHA-256 checksum.
- The launcher verifies the checksum before replacing AstryxCore. Keep the URL and hash together when publishing a new build.
- OptiFine is downloaded from its official site during installation; it is not hosted here.

Launcher data and logs are stored in `%AppData%\AstryxClient`. Extra Forge mods belong in `instances\default\mods`; use the launcher's mod manager to add or disable them.

When reporting an issue, include the launcher version and relevant logs. Remove account details and tokens first.
