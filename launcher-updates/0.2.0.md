Astryx 0.2.0 for Windows x64

Adds Fabric preview profiles for Minecraft 1.20.1, 1.21.1 and 1.21.4 alongside the existing Forge 1.8.9 client. Choose Versions → Astryx Client, select a preview and install it. Each version has its own mods, saves and settings.

The previews include an Astryx title screen, configurable HUD, FPS, ping, CPS, coordinates, BedWars resources, held stack count, hold-C zoom and desktop Discord presence. Open Astryx settings from the title screen or press Right Shift in a world. The full 1.8.9 wardrobe, social menus and remaining modules are still exclusive to the Forge release.
